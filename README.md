# 漫画リーダー（試作版 0.1）

BOOXなどのAndroid電子ペーパー端末向け。WebDAVのJPEG入りZIP/CBZを読む試作です。Android Studioでこのフォルダを開き、Gradle同期後にビルドします（Android SDK 35、JDK 17、Android Gradle Plugin 8.9.2）。実機検証はまだ行っていません。Gradle wrapperは含みません。Android Studioの環境でGradleを用意してください。

## 接続
1. サーバーのHTTPS WebDAVフォルダURL（末尾 /）と、必要ならユーザー名・パスワードを設定します。HTTPは許可しません。
2. mTLSを使う場合は、Androidの設定からユーザー証明書としてPKCS#12（.p12/.pfx）をインストールしてから、アプリの「証明書を選択」で選びます。AndroidのKeyChainを使い、秘密鍵ファイルをアプリにコピーしません。機器のポリシーや証明書の用途によって選択できない場合があります。
3. Cloudflare側のmTLS設定とWebDAVの認証設定は別途必要です。Cloudflare Accessのログイン画面やサービス・トークン方式は未対応です。

## 制約・注意
- HTTP Rangeと正しいContent-Rangeに対応したサーバーが必要です。Cloudflare経由でも206応答が必要です。非対応時の全体ダウンロードへのフォールバックはありません。
- 通常のZIPのみ。ZIP64、暗号化ZIP、分割ZIP、JPEG以外は未対応。ZIPの中央ディレクトリは最大8MB、個々の圧縮画像は最大32MBです。
- 通信・ZIPのテストは限定的で、実サーバーやBOOX実機での動作は未確認です。大切なデータの唯一の閲覧手段にしないでください。
- ページ番号・既読情報・見開き調整位置は端末内に保存します。アプリ削除で消えます。WebDAVに書き込みません。パスワードはAndroidのアプリ専用ストレージに保存されます（暗号化保管は未実装）。
- 見開き調整は現在のページを区切りとして以降の組み合わせを再計算します。画像の縦横比で横長画像を単独表示。単独表示の手動切り替え、読了の手動変更は今後の実装対象です。
- HTTP BASIC認証対応。認証方式によっては接続できません。URL変更時、同じ本も別の本として扱います。
- 読書画面からホームへ戻るボタンを表示します。直近の読書履歴は未読了の本のみ。最後のページを開くと自動で既読になります。
- 戻る操作は、その読書セッション内で進んだページは正確に戻ります。アプリ再起動後の最初の「前へ」は2ページ前に戻る簡易実装で、横長画像や調整位置の直前ではずれる場合があります。
- 読み込み中の処理のキャンセル、余白カット、任意ページ移動、WebDAV応答のETag検証、リトライUIやクライアント証明書の実機確認は今後必要です。見開き表示の調整は現在のページの次を区切りにします。

## GitHub ActionsでAPKを作成
`main` へのpush時、pull request時、またはActions画面での手動実行時に、GitHub ActionsがデバッグAPKをビルドします。GitHubの **Actions → Android APK → 対象の実行 → Artifacts → manga-reader-debug** からZIPをダウンロードして、中のAPKを取り出してください。ダウンロードにはGitHubへのログインが必要な場合があります。成果物の保存期間は30日です。

これはテスト用のdebug APKです。Google Play公開向けの署名済みrelease APKではありません。実機にインストールするには、Android側で提供元不明アプリのインストール許可が必要な場合があります。GitHub上でビルドが成功したか、Actionsの結果をご確認ください。

## ダウンロードと読了（試作）
- 開く際はHTTP Rangeで先に必要なページを取得し、同時にZIP全体の保存を別スレッドで開始します。保存完了後は端末内のコピーから読みます。Range未対応サーバーには現状未対応です。
- 通信切断、容量不足、またはアプリのプロセス終了等で保存が中断される場合があります。Androidのバックグラウンドサービスは使っていないため、アプリを閉じた後の完了は保証されません。次回その本を開くと最初から再ダウンロードします。完全なオフライン起動は未対応です。
- ダウンロード完了から30日経過したファイルは、次にアプリを起動した際またはファイル参照時に削除します。30日ちょうどに削除する常駐処理はありません。読み終わって最終ページの次へ進むと保存ファイルを削除し、次の巻またはホームを選べます。読書位置や既読情報は残ります。
- 次の巻は、同じWebDAVフォルダ内のZIP/CBZをファイル名の自然順に並べた直後のファイルです。フォルダの一覧取得に失敗した場合はホームへ戻れます。
- 保存完了前にサーバー上のZIPが差し替わると、ページの読み込みに不整合が起きる可能性があります。ETagによる整合性検証は未実装です。

## 基本テスト
`tests/run-jvm-tests.sh` はZIP読み込みとダウンロード保存・期限切れ・削除のJVMテストです。Android APIとWebDAVは代用品を使用し、画面・実機・実ネットワーク・証明書の検証にはなりません。GitHub Actionsでも実行します。
