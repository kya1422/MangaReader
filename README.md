# 漫画リーダー（試作版 0.1）

BOOXなどのAndroid電子ペーパー端末向け。WebDAVのJPEG入りZIP/CBZを読む試作です。Android Studioでこのフォルダを開き、Gradle同期後にビルドします（Android SDK 35、JDK 17、Android Gradle Plugin 8.9.2）。実機検証はまだ行っていません。Gradle wrapperは含みません。Android Studioの環境でGradleを用意してください。

## 接続
1. サーバーのHTTPS WebDAVフォルダURL（末尾 /）と、必要ならユーザー名・パスワードを設定します。HTTPは許可しません。
2. mTLSを使う場合は、Androidの設定からユーザー証明書としてPKCS#12（.p12/.pfx）をインストールしてから、アプリの「証明書を選択」で選びます。AndroidのKeyChainを使い、秘密鍵ファイルをアプリにコピーしません。機器のポリシーや証明書の用途によって選択できない場合があります。
3. Cloudflare側のmTLS設定とWebDAVの認証設定は別途必要です。Cloudflare Accessのログイン画面やサービス・トークン方式は未対応です。

## 制約・注意
- HTTP Rangeと正しいContent-Rangeに対応したサーバーが必要です。Cloudflare経由でも206応答が必要です。非対応時の全体ダウンロードへのフォールバックはありません。
- 通常のZIPのみ。ZIP64、暗号化ZIP、分割ZIP、JPEG以外は未対応。ZIPの中央ディレクトリは最大8MB、個々の圧縮画像は最大32MBです。
- 通信・ZIPのテストは限定的で、実サーバーやBOOX実機での動作は未確認です。大切なデータの唯一の閲覧手段にしないでください。
- ページ番号・既読情報・見開き調整位置は端末内に保存します。アプリ削除で消えます。WebDAVに書き込みません。WebDAVパスワードはAndroid Keystore内の鍵を用いてAES-GCMで暗号化し、アプリ専用ストレージに保存します。旧バージョンの平文パスワードは、設定を開いたときまたはWebDAVに接続するときに、暗号化と保存に成功した後に削除します。アンインストール後の復元はできません。
- 見開き調整は現在のページを区切りとして以降の組み合わせを再計算します。画像の縦横比で横長画像を単独表示。単独表示の手動切り替え、読了の手動変更は今後の実装対象です。
- HTTP BASIC認証対応。認証方式によっては接続できません。URL変更時、同じ本も別の本として扱います。
- 読書画面からホームへ戻るボタンを表示します。直近の読書履歴は未読了の本のみ。最後のページを開くと自動で既読になります。
- 再起動後やページ移動後に「前へ」を押す場合、見開き位置を先頭から計算します。横長ページや見開き調整を考慮しますが、画像の縦横情報を確認するため待ち時間が発生する場合があります。
- 読み込み中の処理のキャンセル、余白カット、任意ページ移動、WebDAV応答のETag検証、リトライUIやクライアント証明書の実機確認は今後必要です。見開き表示の調整は現在のページの次を区切りにします。

## GitHub ActionsでAPKを作成
`main` へのpush時、pull request時、またはActions画面での手動実行時に、GitHub Actionsが署名済みrelease APKをビルドします。GitHubの **Actions → Android APK → 対象の実行 → Artifacts → manga-reader-release** からZIPをダウンロードして、中のAPKを取り出してください。ダウンロードにはGitHubへのログインが必要な場合があります。成果物の保存期間は30日です。

これは固定鍵で署名されたrelease APKですが、アプリ自体は試作段階です。実機にインストールするには、Android側で提供元不明アプリのインストール許可が必要な場合があります。GitHub上でビルドが成功したか、Actionsの結果をご確認ください。

## ダウンロードと読了（試作）
- 開く際はHTTP Rangeで先に必要なページを取得し、同時にZIP全体の保存を別スレッドで開始します。保存完了後は端末内のコピーから読みます。Range未対応サーバーには現状未対応です。
- 通信切断、容量不足、またはアプリのプロセス終了等で保存が中断される場合があります。Androidのバックグラウンドサービスは使っていないため、アプリを閉じた後の完了は保証されません。次回その本を開くと最初から再ダウンロードします。完全なオフライン起動は未対応です。
- ダウンロード完了から30日経過したファイルは、次にアプリを起動した際またはファイル参照時に削除します。30日ちょうどに削除する常駐処理はありません。読み終わって最終ページの次へ進むと保存ファイルを削除し、次の巻またはホームを選べます。読書位置や既読情報は残ります。
- 次の巻は、同じWebDAVフォルダ内のZIP/CBZをファイル名の自然順に並べた直後のファイルです。フォルダの一覧取得に失敗した場合はホームへ戻れます。
- 保存完了前にサーバー上のZIPが差し替わると、ページの読み込みに不整合が起きる可能性があります。ETagによる整合性検証は未実装です。

## 基本テスト
`tests/run-jvm-tests.sh` はZIP読み込みとダウンロード保存・期限切れ・削除のJVMテストです。Android APIとWebDAVは代用品を使用し、画面・実機・実ネットワーク・証明書の検証にはなりません。GitHub Actionsでも実行します。

## 固定署名の設定
CIで継続的に上書き更新可能なAPKを作るため、リポジトリのActions secretsに `MANGA_KEYSTORE_BASE64`、`MANGA_KEYSTORE_PASSWORD`、`MANGA_KEY_ALIAS` を設定してください。これらがない場合、CIはデフォルト鍵に切り替えずに失敗します。キーストアと鍵は同一パスワードとしています。署名鍵とパスワードは公開せず、安全にバックアップしてください。鍵を紛失すると既存のアプリを上書き更新できません。すでに別の鍵で署名したAPKからの最初の移行にはアンインストールが必要で、アプリデータも消えます。Pull request元でSecretsが使えない場合は署名ステップが失敗します。

## User-Agent
WebDAVのフォルダ一覧（PROPFIND）、部分取得・ダウンロード（GET）のいずれも `MangaReader/0.1 (Android)` を送信します。User-Agentは偽装できるため、アクセス認証として単独で使用しないでください。

## 読書画面
中央タップで上部操作と下部のサムネイル列を画像上に重ねて表示・非表示します。表示中も漫画画像の領域は変わりません。サムネイルは選択ページの前後最大10ページずつで、横スクロールとタップが可能です。シークバーで離れた位置を選べます。サムネイルは順次取得するため、ダウンロード中や遅い回線では表示に時間がかかる場合があります。BOOX実機でのオーバーレイ配置・性能は未検証です。

サムネイルやシークバーでページを選ぶと、表紙・横長画像・保存済みの見開き調整を考慮し、そのページを含む見開きを開きます。初回は先頭から画像の縦横を調べるため、選択先が遠い場合やWebDAVが遅い場合は時間がかかることがあります。確認済みの縦横情報は開いている間メモリーに保持します。

## アプリ内更新
リポジトリが公開されている場合、接続設定の「アプリの更新を確認」から最新GitHub ReleaseのAPKを取得できます。署名・アプリID・バージョンを確認したうえでAndroidのインストール確認画面を開きます。初回はAndroidで「この提供元のアプリを許可」が必要です。許可設定後はもう一度更新確認を行ってください。Androidがインストールを最終確認します。

`main`へのpushまたは手動実行で、署名付きrelease APKを`build-<Actions実行番号>`としてGitHub Releasesに公開します。Actions実行番号からversionCodeを生成します。Secrets未設定・ビルド失敗時には公開しません。GitHub Releasesはリポジトリ公開後は誰でもダウンロードできるため、公開前にソースと成果物の内容をご確認ください。アプリは試作・テスト段階です。署名鍵は絶対に公開しないでください。

初回のみ、この更新機能を搭載したAPKをGitHub ReleasesまたはActionsから手動インストールする必要があります。旧APKと同じ署名鍵なら上書き可能です。インストール済みの署名と異なる鍵のAPKは更新時に拒否されます。GitHubのAPI利用制限やネットワーク障害時は更新確認ができません。

## 画面回転
アプリは横向き固定です。端末の向きに合わせて横向きのまま180度回転できます。回転による画面再作成を避け、読書中の位置・画面を維持します。端末やOSの回転設定によって挙動が異なる場合があります。

読書中に中央をタップ → 「見開き左右」から、右開き（先のページが右）／左開き（先のページが左）を本ごとに選べます。左開きにしても、左タップで進み右タップで戻る操作は変わりません。横長の画像は1枚で表示します。

## 次巻の先読み
表示済みの範囲が全体の90％に達すると、同じWebDAVフォルダ内でファイル名の自然順に並べた次のZIP/CBZを1冊だけ先読みします。設定画面で無効にできます。現在の本のダウンロードと同じ保存キューを使い、前のダウンロードが終わってから始まる場合があります。先読み済みファイルは通常の保存と同じく、読了時または保存完了後30日以降の次回チェック時に削除します。読書位置と既読情報は削除しません。アプリが終了・OSに停止された場合のダウンロード継続は保証されず、失敗時は次回その本を開いたときに取得します。

## 見開きの任意OCR判定（試作）
読書画面の中央タップ → 自動判定を選ぶと、現在のページから最大12ページの下端の左右を順番にOCRし、数字のページ番号の位置と奇偶を参考に表示順とずれの候補を提示します。ページ番号が4件未満、左右の傾向が矛盾、見開きのずれの根拠不足などの場合は該当部分を変更しません。検出は推測であり、適用前に確認が必要です。表紙、横長ページ、広告や誤認識等により間違う場合があります。タイトルや漢数字の認識には対応していません。

解析は任意実行で、1ページずつ縮小表示用画像と左右の下端の小さい画像を使用し、終了後に解放します。大きな画像（ZIP展開前または展開後8MiB超）は解析をスキップし、見開きずれは判定しません。OCR中もWebDAVの取得や次巻保存が動く場合があり、メモリー・CPU・通信量への実際の影響は端末で要確認です。

Google ML Kitの同梱テキスト認識モデルを利用します。Googleによると画像・認識結果は端末内で処理され、サーバーへ送信されませんが、ML Kitは性能や利用状況の指標をGoogleへ送信する場合があります。詳細: https://developers.google.com/ml-kit/terms 。OCRライブラリの追加によりAPKサイズは増加します。
