# 漫画リーダー

BOOXなどのAndroid電子ペーパー端末向けの、フォルダ型の漫画ビューアです。HTTPS WebDAV上のZIP/CBZ・RAR/CBRを読みます。指定したWi-Fiでは、同じ漫画フォルダを公開しているSamba（SMB2/3）を優先することもできます。本棚への登録は不要です。

- 対応OS：Android 8.0以降（API 26以上）。画面は横向きです。
- 対応画像：JPEG・PNG。ZIP/CBZ、非暗号化・非ソリッド・単一ボリュームのRAR4/RAR5/CBR。
- 現在も試作・改善中です。ユーザー環境でBOOXとSamba接続の基本動作は確認されていますが、すべての端末・サーバー・ネットワーク条件で検証されたわけではありません。大切なデータの唯一の閲覧手段にしないでください。

## インストールと更新

[GitHub Releases](https://github.com/kya1422/MangaReader/releases/latest)の `MangaReader.apk` をダウンロードし、Androidのインストーラーで開いてください。インストールには提供元の許可が必要な場合があります。

継続して同じ署名鍵で公開されたAPK同士は、通常、アンインストールせずに上書きできます。別の署名鍵のAPKは上書きできません。**アンインストールすると端末内の読書履歴や設定が消えます。**

接続設定の「アプリの更新を確認」ではGitHub Releaseのバージョンを確認し、ユーザーの操作でブラウザのReleaseページを開きます。アプリ自身はAPKをダウンロード・インストールせず、インストール権限も要求しません。GitHubのAPI制限や通信障害時には更新確認ができないことがあります。

Play プロテクトが有害と警告した場合は、保護を無効にせずインストールを中止し、警告内容の確認やGoogleによる再審査を検討してください。署名・ハッシュが一致しても、アプリの安全性の証明にはなりません。

## 初期設定：WebDAV

1. アプリを開き、「接続設定」にWebDAVの **HTTPS URL** と、必要なユーザー名・パスワードを入力します。URLは漫画フォルダのルートを指定してください。末尾の `/` は保存時に補われます。HTTPは使えません。
2. クライアント証明書を使う場合は、設定画面の「証明書をインストール」またはAndroidの設定からPKCS#12（`.p12` / `.pfx`）をインストールし、「インストール済み証明書を選択」で選んでください。選択後、最後に「保存」を押します。秘密鍵ファイルをアプリにコピーせず、Android KeyChainを使用します。端末のポリシーや証明書の用途によっては選択できません。
3. 必要なWebDAV認証と、Cloudflareを使う場合のmTLS設定はサーバー側で行います。HTTP Basic認証に対応しています。Cloudflare Accessのログイン画面・サービストークン方式には対応していません。

WebDAVで未保存の漫画を読むには、GETの **HTTP Rangeと正しい `206 Content-Range`** が必要です。Cloudflare経由の場合も同様です。Range非対応時に、全体を先にダウンロードしてから開くフォールバックはありません。

WebDAVのPROPFINDとGETのUser-Agentは `MangaReader/0.1 (Android)` です。User-Agentは偽装可能なため、これだけをアクセス認証に使わないでください。

## 自宅Wi-FiでSambaを優先する（任意）

接続設定で「指定Wi-FiではSambaを優先する」をオンにし、次を設定します。

- 自宅Wi-Fiの名前（SSID）。「現在のWi-Fi名を取得」で入力することもできます。
- SambaサーバーのプライベートIPv4アドレス、共有名、ユーザー名、パスワード。ポートは445です。
- **共有の直下とWebDAVルートが同じフォルダ・同じ階層になること**。共有内のサブフォルダをルートに指定する機能はありません。

最後に「保存」を押してください。現在の実装では、SSIDの自動入力だけでなく、手入力したSSIDと現在の接続先を照合するときにも、Androidの「正確な位置情報」権限が必要です。端末の位置情報設定もオンにする必要がある場合があります。アプリは位置情報そのものを取得・送信する目的では使用しません。権限を許可しない、SSIDを取得できない、またはSSIDが一致しない場合はWebDAVを使います。

指定Wi-Fiでも、Sambaの共有への接続・認証や読み始める前の取得が失敗すれば、WebDAVへのフォールバックを試みます。読み込み開始後に通信が切れた場合は、異なるデータが混ざることを避けるため、途中でWebDAVに切り替えずエラーにします。本を開き直してください。新着探索中の子フォルダ単位のアクセス拒否などは、そのフォルダの取得失敗として数え、残りの探索ではSambaを使い続けます。

SMB1は使用せず、SMB2/3の署名を必須にしています。通信が必ず暗号化されるわけではありません。またSSIDやIPアドレスは偽装可能で、接続先の真正性を保証しません。信頼できるLAN、強固なパスワードと専用の**読み取り専用**Sambaアカウントを使用し、SMBをインターネットに公開しないでください。

読書位置や表紙は、WebDAVのURLを論理的な識別子として使用します。SambaとWebDAVが同じ内容を指すようにしてください。以前のWebDAV表紙などを引き継ぐため、Sambaでフォルダを開く際にWebDAVの一覧を短時間照合する場合があります。WebDAVに接続できずURLの表記を照合できない場合、既存の表紙が見つからず一時的に再取得されることがあります。元の履歴や表紙設定をこの照合で削除することはありませんが、異なるURL表記が常に同一視される保証はありません。照合にはインターネット・WebDAV接続も必要です。

読書中の操作欄には直近の読み込み元の目安として「端末保存」「自宅Samba」「WebDAV」を表示します。WebDAVに切り替わった場合は、理由の概要が表示される場合があります。

## フォルダとホーム

- ホームの「フォルダ」から接続先を階層順に開きます。「最近読んだ本」は読みかけの本を直接開き、「読みかけのシリーズ」は該当フォルダを開きます。
- フォルダ内の検索は、**現在のフォルダ直下のフォルダ名のみ**が対象です。検索中は漫画ファイルを表示しません。サブフォルダの中は検索しません。大文字・小文字や全角・半角の違いは区別しません。
- 「作品名順」で昇順・降順を切り替えます。表示名を基準に日本語の照合順と数字の自然順で並べ、フォルダを先に表示します。漢字の読みを辞書で引く方式ではありません。次巻の選択・先読みはファイル名の自然順の昇順です。

### 新着・未読

ホームでは接続先の子フォルダを再帰的に探索し、**作成日時が現在から1か月以内で、端末に読書履歴がない**ZIP/CBZ/RAR/CBRを新しい順に表示します。WebDAVでは `DAV:creationdate`、SambaではSMBが返す作成日時を使用します。取得できない日時を更新日時で代用しません。未来の日付も対象外です。非表示フォルダは探索しません。

作成日時は厳密な追加日とは限りません。特にApache `mod_dav_fs` の `creationdate` はctimeを返す実装があり、権限などのメタデータ変更によって古い漫画が新着になる場合があります。SambaとWebDAVで返される日時も、サーバー実装によって異なる場合があります。

初回探索後は結果を端末メモリー内で再利用します。期限後にホームを開き直すか、「更新」を押すと再探索します。アプリ再起動後も再探索します。

| 探索結果 | 再利用 |
| --- | --- |
| 完了・失敗なし・上限未到達 | 30分 |
| 完了・取得失敗1〜5フォルダ、かつ少なくとも1フォルダ取得成功 | 5分。失敗件数を表示 |
| 完了・探索または候補の上限に到達 | 5分。不完全であることを表示。取得失敗が6件以上などの場合は保存しない |
| 途中で中断、ルート取得失敗、取得失敗6件以上 | 再利用しない |

探索は最大10,000フォルダ・深さ64階層、候補は最大5,000冊、表示は新しい順に最大100冊です。途中結果、取得失敗、上限到達を画面に表示します。画面を離れると探索を中断しますが、通信の種類や状態によって中断に時間がかかる場合があります。新着探索では漫画ファイル全体はダウンロードしません。

## 読書操作

- 左タップで進む、右タップで戻る、中央タップで操作欄の表示・非表示。スワイプでも移動できます。
- 画面は横向きで、端末の設定に応じて横向きのまま180度回転します。操作欄は漫画画像の上に重ねて表示します。
- 縦長ページは原則2ページの見開き、横長または正方形のページは1枚で表示します。「見開き左右」でページの左右配置を本ごとに変更しても、タップ方向は変わりません。
- 「見開き調整」では現在のページを直前のページと組み合わせる方向にずらせます。先頭や横長ページなど、組み合わせられない場合は変更しません。本の調整をまとめて解除することもできます。
- サムネイルは選択ページの前後最大10ページずつです。シークバーは右が先頭、左が後のページです。選んだページを含む見開きを開きます。初回や遠いページへの移動では、先頭から画像の縦横を確認するため待つ場合があります。
- 「文字・線の濃さ」は標準・弱・強を選べ、全書籍共通です。元画像は変更しません。カラーや網点にも影響し、消えた細線を必ず復元できるわけではありません。
- 本を開けない場合は再試行やフォルダへの復帰、ページ表示の失敗時は再試行や次ページへの移動ができます。

ページ数とファイルサイズを照合して保存済みの画像の縦横情報を再利用します。同じURL・ページ数・サイズでファイルを差し替えた場合は古い判定が残る可能性があります。ファイルの差し替えは読書中・保存中を避けてください。ETagを使った整合性検証はありません。

## 保存、次巻、読了

本を開くと、必要な部分を先に読みながら、漫画ファイル全体の保存を別スレッドで開始します。保存完了後は端末内のコピーから読みます。SambaではSMBの部分読み取り、WebDAVではHTTP Rangeを使います。

- 次巻の自動保存は、表示済み範囲が**80％**に達すると開始を試みます。設定の「読み終わる前に次巻をダウンロード」で無効にできます。同じフォルダの次のZIP/CBZ/RAR/CBRが対象です。
- 現在の本と次巻は同じ保存キューを使うため、現在の保存が終わるまで次巻の保存が待つ場合があります。80％から始めても、読了までの完了は保証されません。
- 読了画面は最終ページからさらに進むと開きます。次巻があれば次巻かホーム、なければホームを選べます。読了時に端末の保存ファイルを削除し、読書位置・既読情報は残します。サーバーの元ファイルは削除しません。
- 保存完了後30日を過ぎたファイルは、次回のアプリ起動時または参照時などに削除します。読書中の本は保護し、閉じた後のチェックで削除します。30日ちょうどに削除する常駐処理はありません。
- 保存済み漫画のキャッシュは最大2 GiBです。容量確保時は、現在開いている本を除き最近使用していない保存済みファイルから削除します。2 GiBを超える本や端末の空き容量が不足する場合は、全体保存を中止し、部分読み取りでの閲覧を試みます。
- 保存はアプリ内の処理であり、アプリ終了・OSによる停止後の完了は保証されません。中断後は次回開いたときに再取得します。完全なオフライン起動には対応していません。

## 表紙

フォルダ画面の「表紙: オン」で表紙を表示します。対象フォルダ直下に漫画があれば、ファイル名の自然順で最初の漫画を選びます。直下になければ子フォルダを名前順に探索します。探索上限は12階層・128フォルダです。先頭JPEGまたはPNGを縮小して保存するため、最初のファイルが1巻でない場合や先頭ページが表紙でない場合は、期待する表紙とは異なります。

横幅が高さの1.2倍を超える画像は見開きスキャンと推測して左半分を使用します。横長の単独画像も切り取られる場合があります。外部の書籍検索サービスにはフォルダ名を送信しません。

**手動指定**する場合は、対象フォルダ名を長押し → 「漫画のページを表紙に選ぶ」 → 対象フォルダ内または子フォルダ内の漫画を開く → 目的ページで中央をタップ → 表紙指定ボタンを押します。見開きでは使用するページを選択できます。白い枠を左右に動かして範囲を決めてください。枠の上下はページ全体に固定され、画像が枠より細ければ画像全体を使います。長押しメニューの「手動の表紙設定を解除」で自動表紙に戻せます。手動表紙の取得に失敗した場合も、設定は自動削除されません。

自動・手動の縮小画像は共通で最大10 MiBを目安に保存され、古いものから削除されます。「表紙を再取得」は保存済みの表紙画像を消して取得し直しますが、手動指定、漫画ファイル、履歴は消しません。元の漫画を移動・削除した場合やページ構成を変更した場合は、手動表紙の解除または再指定が必要です。

## 非表示と履歴

フォルダ名を長押しし「このフォルダを非表示にする」を選ぶと、フォルダとその子孫を一覧・検索・新着・読みかけ・履歴から隠します。非表示フォルダが親の表紙に表示されないよう、親の表紙も隠す場合があります。解除は「接続設定」→「非表示タイトル」から行います。親にも非表示設定がある場合は親も解除してください。

これは**表示フィルター**であり、パスコードやアクセス制御ではありません。他のアプリやサーバーからの閲覧は防げません。対象年齢の自動取得・判定は未対応です。

「接続設定」→「閲覧履歴を管理」から履歴を個別に削除できます。対象は端末内の読書位置・既読状態・見開き調整・保存した漫画ファイルです。保存中なら中止します。WebDAV・Samba上の元ファイルは削除しません。

読書履歴、設定、手動表紙の指定先は端末内に保存し、サーバーには書き込みません。アプリをアンインストールすると失われます。アプリのAndroidバックアップは無効です。WebDAVとSambaのパスワードはそれぞれ別のAndroid Keystore鍵で暗号化して保存します。鍵が使えなくなった場合、設定画面の各パスワードのリセットボタンで保存値と鍵を削除し、再入力できます。クライアント証明書・漫画・履歴は削除しません。

## アーカイブの制約

- ZIP/CBZ：通常の単一ボリュームZIPの保存・Deflate方式に対応。ZIP64、暗号化ZIP、分割ZIPは未対応です。中央ディレクトリは最大8 MiB、1画像の圧縮データは最大32 MiB、展開後は最大80 MiBです。
- ZIP内ファイル名は、UTF-8フラグがない場合にUTF-8・Shift-JIS・CP437の順で推測します。文字コード情報がないため誤判定もあります。
- RAR/CBR：RAR4/RAR5の非暗号化・非ソリッド・単一ボリュームに対応。暗号化・ソリッド・分割RARは未対応です。辞書、画像の圧縮データ、画像の展開データはそれぞれ最大32 MiBです。
- RARは開くときにヘッダーの走査が必要です。開いている間は再利用しますが、ヘッダー位置の永続保存はありません。未保存・多数ページ・高遅延回線ではZIPより遅くなることがあります。
- JPEG・PNG以外の画像形式は対象外です。大きな画像は読み込めない場合があります。

## 開発・テスト

Android Studioでこのフォルダを開きます。Android SDK 35、JDK 17、Android Gradle Plugin 8.9.2を使用します。Gradle wrapperは同梱していません。GitHub ActionsではGradle 8.11.1、Android Build Tools 35.0.0を使用しています。ローカルのデバッグビルド例：

```sh
gradle :app:assembleDebug
```

ローカルのデバッグAPKは通常デバッグ鍵で署名され、公開APKとは署名やバージョン番号が異なるため、そのまま上書きできない場合があります。アンインストールするとアプリデータは消えます。

基本のJVMテストは次で実行します。Android APIやネットワークには代用品を使用しており、BOOX実機・実サーバー・証明書の検証には代わりません。

```sh
./tests/run-jvm-tests.sh
```

RAR4/5の追加テストは、手元のサンプルとJunrar・SLF4JのJARを指定して `tests/run-rar-samples.sh` を実行します。SMB2の追加テストにはローカルの使い捨てサーバーとSMBJ依存JARが必要です。手順・テスト用資格情報は [`tests/smb/README.md`](tests/smb/README.md) を参照してください。サンプル漫画・実際の認証情報をリポジトリに追加しないでください。

### GitHub Actionsと固定署名

`main`へのpush、またはActionsの手動実行で署名付きrelease APKをビルドし、テストと署名証明書を確認します。`main`で実行した場合は `build-<Actions実行番号>` としてGitHub Releasesに公開します。Actionsの **Android APK → 対象実行 → Artifacts → manga-reader-release** にも30日間保存します。ArtifactsのダウンロードにはGitHubへのログインが必要な場合があります。Actions実行番号からversionCodeを生成します。

署名にはActions secretsの `MANGA_KEYSTORE_BASE64`、`MANGA_KEYSTORE_PASSWORD`、`MANGA_KEY_ALIAS` が必要です。未設定なら失敗します。キーストアと鍵は同一パスワードを使用します。このリポジトリのワークフローは既定の署名証明書のSHA-256も検証するため、別の鍵を使うフォークでは検証設定の変更が必要です。署名鍵とパスワードは公開せず安全にバックアップしてください。鍵を紛失すると、同じ鍵で署名された既存アプリを上書き更新できなくなります。フォークからのPull RequestなどでSecretsを使えない場合は署名ビルドが失敗します。

## 使用ライブラリ

RARにはJunrarを使用します。UnRARのコードをRAR（WinRAR）互換の圧縮アーカイバーの開発に使用することはできません。UnRAR License全文は [`app/src/main/assets/licenses/junrar.txt`](app/src/main/assets/licenses/junrar.txt) に同梱しています。SMBにはSMBJとその依存ライブラリを使用します。Apache License 2.0、Bouncy Castle、SLF4J、mbassadorのライセンスは [`app/src/main/assets/licenses/`](app/src/main/assets/licenses/) に同梱しています。
